# 🔍 Image Forensics Metadata Extractor

A Python-based digital forensics tool that extracts hidden metadata from images.

## Features

* 📱 Device Information
* 📅 Date & Time Taken
* 📍 GPS Coordinates
* 🌍 Google Maps Location
* 🖼️ Image Resolution
* 📷 Camera Model Detection

## Technologies Used

* Python
* Pillow
* ExifRead
